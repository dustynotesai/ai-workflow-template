## 主管要的

星期五下午，主管傳來一句：

> 「下週一要報告，幫我整理這個月客戶最常反映的問題。」

## 專案助手怎麼找的

沒有從頭翻資料夾，照地圖的順序找：

1. **地圖**：讀 `AGENTS.md`，專案表寫著主管月報要用的是 001 客戶常見問題。
2. **目錄**：打開 [`wiki/index.md`](../../wiki/index.md)，找到 001：新品上市時整理的，三個專案都在用。
3. **筆記**：讀 [001 客戶常見問題](../../wiki/客戶常見問題.md)，排名、筆數、出處都在裡面。新品上市的資料夾不用打開，客戶回饋的表也不用重算。
4. **原始檔**：只有要查證一個數字時，才點那一點後面的連結打開 `raw/`。
5. 寫成下面的大綱。筆記裡「需要人工確認」的，全部帶過來。

## 第一版大綱：10 月客戶最常反映的問題

1. 這個月收到幾筆：10 筆，2026-10-02 到 2026-10-22（[001](../../wiki/客戶常見問題.md)）
2. 第一名：電子發票沒有上傳成功，4 筆，3 筆還沒處理完（[001](../../wiki/客戶常見問題.md)）
3. 第二名、第三名：第一次設定太難 2 筆、客服電話等太久 2 筆（[001](../../wiki/客戶常見問題.md)）
4. 其他：想加行動支付 1 筆、續約費用看不懂 1 筆（[001](../../wiki/客戶常見問題.md)）
5. 正在做的：新版說明書加「發票沒上傳怎麼辦」；產品組 10/28 報告發票失敗的原因（[001](../../wiki/客戶常見問題.md)）
6. 要主管決定的：【例如：要不要先加派下午的客服】
