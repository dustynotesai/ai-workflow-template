# 客服改善（範例）

> 狀態：剛開始
> 更新：2026-10-21
> 截止：12 月底

## 要做到什麼

客服電話不讓客戶等超過 5 分鐘；最常被問的問題做成一份自助說明。【範例：換成你自己的目標】

## 現在做到哪

客戶回饋**不用重新整理**：新品上市時已經整理過一頁 [001 客戶常見問題](../../wiki/客戶常見問題.md)，直接用。

- 跟客服有關的：「客服電話等太久」2 筆、「第一次設定太難」2 筆（看那頁的「重點」）。

## 下一步

1. 用 [05 處理表格](../../prompts/05-處理表格.md) 把客戶回饋照「管道」數一次（電話、信箱、問卷、業務轉達各幾筆），結果存在這個資料夾。
2. 把「第一次設定太難」那 2 筆寫成自助說明的初稿。
3. 問客服：下午幾點電話最多。原始檔沒有寫，查到了存進 `raw/`。
