# AI 總部起手包：一個資料夾管你所有的事，AI 越用越懂你

AI 不會自己變聰明。你上次說過「不要漸層」，換一篇貼文它又給你漸層；你不要的東西，它會一直做。

問題不在 AI，在它每次都從零開始。這個資料夾給它三樣東西：

1. **一張地圖**：你有哪些事在做、各放在哪、做到哪。
2. **一份共用的資料**：品牌表、發過的貼文、成效數字，整理一次，每件事都去同一個地方拿。
3. **一本它學到的你**：你糾正過它的、教過它的，下次開工前先讀。

不用會寫程式，也不用打開「終端機」那個黑色視窗。照下面做，大約 5 分鐘。

---

## 先看兩種放法

很多人習慣照「事情」放：一件事一個資料夾，需要的東西都抄一份進去。

```
我的IG/
└─ 品牌顏色.txt    ← 貼了一份
我的YouTube/
└─ 品牌顏色.txt    ← 又貼一份。顏色改了，兩份都過期
```

這個資料夾照「種類」放：資料只放一次，每件事都去同一個地方拿。

```
AGENTS.md            地圖：所有專案、在哪、交給誰
raw/                 原始資料（放了就不改）
  表格/  對話/  文件/  查的資料/  回饋/  做法/
wiki/                AI 整理的
  index.md           目錄
  品牌資料.md         筆記 001：IG、YouTube 都從這裡拿品牌
  projects/          專案頁：每件事做到哪、下一步、更新日期
  lessons/           教訓：AI 學到的你
projects/            每件事做出來的東西（貼文、封面）
  我的IG/  我的YouTube/
templates/  prompts/  archive/  CLAUDE.md  .claude/
```

## 一個資料夾，管你所有的事

[`AGENTS.md`](AGENTS.md) 最上面是一張地圖：

| 區域 | 專案 | 一句話 | 專案頁 |
|---|---|---|---|
| 貼文 | 我的IG | 小圓匙手沖的 IG，每週三發一篇輪播 | [我的IG](wiki/projects/我的IG.md) |
| 影片 | 我的YouTube | 手沖教學影片，第一支先做封面 | [我的YouTube](wiki/projects/我的YouTube.md) |

每個專案有一頁**專案頁**：做到哪、下一步、截止、更新日期。AI 每次做完都會更新它。

所以開一個新的對話，問一句：

> 我所有的專案現在做到哪？

AI 讀地圖跟兩頁專案頁就答得出來，不用打開每個資料夾（[07 所有專案做到哪](prompts/07-所有專案做到哪.md)）。新增一件事也是一句話：開資料夾、地圖加一行、寫專案頁（[04 新增一個專案](prompts/04-新增專案.md)）。

專案不一定要放在這個資料夾裡：可以是自己的資料夾、別的地方，甚至是別的 git repo，地圖寫清楚在哪就好。

## 它怎麼學

```
1. 開工前     AI 先讀地圖、那件事的專案頁、你的教訓（wiki/lessons/）
2. 你糾正它   「顏色只用墨綠跟芥末黃，不要漸層」→ 它先改對，把你的原話存進 raw/回饋/
3. 變成教訓   寫一條「照品牌做」，階段：試用中
4. 下一件事   做 YouTube 封面的時候，開工前讀到這條，你沒講也照做，記在「套用紀錄」
5. 越用越準   照做 3 次都沒再被糾正 → 問你要不要升成「保留」
6. 教了 3 次   同一件事你教了 3 次 → 問你要不要寫成固定做法，之後一句話就好
```

**還沒決定的事，它先問你。** 每一頁專案頁有一區「還沒決定的事：問我，不要猜」（例如「封面要不要放我的臉？」）。做到那一件，AI 停下來問你，不會自己猜一個、做出你不要的東西；你回答了，它搬到「已決定」寫上日期，之後不再重新討論。

每次做完，AI 會問自己一句：**「下次還要重講嗎？」**（這叫收尾，`capture`）。要，就把最小的一份記在對的地方；不用，就什麼都不寫。忘了的話，貼 [08 收尾](prompts/08-收尾.md)；它做錯了，貼 [09 這裡錯了](prompts/09-這裡錯了.md)。

**教訓跟著你，不跟著專案。** 在我的IG學到的事，我的YouTube也用得上。

### 四個地方：AI 的記憶放哪

| 影片裡的說法 | 在這個資料夾 | 放什麼 |
|---|---|---|
| 家規 | `CLAUDE.md`（規則寫在 `AGENTS.md`） | 每次開工都要照的規則。裡面有一條：只要我糾正你，就把這次的教訓整理下來，放到對的地方 |
| 便利貼 | `wiki/lessons/` | 教訓：你糾正過它的事，一條一份。不放在單一專案裡，換專案一樣先讀 |
| Skill（食譜） | `.claude/skills/` | 固定做法：收尾 `capture`，還有你教過 3 次的事 |
| 知識庫 | `raw/`、`wiki/` | 共用資料：品牌表、發過的貼文，每個專案都去同一個地方拿 |

## 一個例子：小圓匙手沖的 IG 跟 YouTube

（虛構的店、虛構的人，資料夾裡的範例檔案就是照這個做的。）

1. 小禾開一間手沖咖啡小店，店名小圓匙手沖。他決定每週三發一篇 IG 輪播（[店裡群組](raw/對話/範例-2026-10-12-店裡群組-IG貼文.md)）。第一篇什麼都沒講，AI 自己做了紫色漸層、三種字體、滿版表情符號，每頁一大段字。
2. 他說：「顏色只用墨綠 #2E5E4E 跟芥末黃 #E0A526，底色淡綠白 #F4F7F5，不要漸層。」版型也講了一次。AI 先改對（[第一篇](projects/我的IG/第一篇-三種濾杯.md)），把原話存進 [`raw/回饋/`](raw/回饋/範例-2026-10-13-IG貼文品牌.md)，自己寫成一條教訓：[照品牌做](wiki/lessons/範例-照品牌做.md)。
3. 下一篇他開新對話，**沒提品牌**。AI 開工先讀教訓，第一版顏色跟版型就對了（[第二篇](projects/我的IG/第二篇-淺焙深焙.md)）。但還有三處要改：標題太長、店章放錯、語氣太像廣告。他再糾正一次，同一條教訓跟著更新。
4. 他把[品牌表](raw/文件/範例-2026-10-22-品牌表.md)跟[一篇真的貼文](raw/文件/範例-2026-10-22-貼文-淺焙深焙.md)放進共用資料 `raw/文件/`，AI 整理成一頁 [001 品牌資料](wiki/品牌資料.md)。
5. 換到我的YouTube 做封面，**什麼都沒交代**。AI 開工先讀同一條教訓：墨綠、芥末黃、標題 5 個字、店章右下角（[封面](projects/我的YouTube/封面-第一次手沖.md)）。
6. IG 跟 YouTube 的品牌都從同一頁 001 拿：顏色一改，兩邊拿到的都是新的。

## 裡面有什麼

| 資料夾 | 放什麼 |
|---|---|
| `AGENTS.md` | 地圖跟規則：所有專案、在哪、開工前讀什麼、做完做什麼。AI 每次先讀這份。 |
| `raw/` | 你的檔案本人：`表格/`、`對話/`、`文件/`、`查的資料/`。**放進來就不改。** `回饋/`、`做法/` 是 AI 記你的原話用的。 |
| `wiki/` | AI 讀完原始資料寫的筆記，一個主題一頁，每一句都標出是從哪個檔案來的。 |
| `wiki/index.md` | 目錄：每一頁筆記一個編號（001、002…）。**AI 找資料先看這裡**，不用把每個檔案翻一遍。 |
| `wiki/projects/` | 專案頁：每件事做到哪、下一步、更新日期。 |
| `wiki/lessons/` | 教訓：AI 學到的你。 |
| `wiki/做法清單.md` | 你教過 AI 幾次的事。到第 3 次，它問你要不要寫成固定做法。 |
| `projects/` | 每件事一個資料夾，放做出來的東西（貼文、封面、清單）跟「這個專案的規則」。 |
| `templates/` | 筆記頁、專案頁、教訓、固定做法的格式。 |
| `prompts/` | 叫 AI 做事的句子，複製貼上就能用。 |
| `archive/` | 做完或不做了的專案。 |
| `CLAUDE.md` | 家規。第一行 `@AGENTS.md` 讓 Claude Code 讀到同一份地圖跟規則。不用動它。 |
| `.claude/` | 給 Claude Code 的：三個角色（整理員、分析員、專案助手）、收尾 `capture`、選用的自動提醒。 |

`raw/`、`wiki/`、`projects/` 這幾個英文名字不要改：地圖跟規則都寫著這幾個名字。`raw/` 裡的種類可以自己加，例如 `raw/收據/`。

> `.claude` 開頭有一個點，Windows、Mac 可能預設看不到，不影響使用。

### 三個角色：照工作分，不照專案分

| 角色 | 做什麼 |
|---|---|
| 整理員 | 你放了新檔案進 `raw/`，它整理成 `wiki/` 的筆記，給編號 |
| 分析員 | 你問問題，它從 `wiki/` 找答案、標出處；也回答「所有專案做到哪」 |
| 專案助手 | 在一件事裡做貼文、做封面、排計畫；照你的教訓做，做完更新專案頁 |

Claude Code 會自己挑角色，你也可以直接說「用 organizer 整理一下」。其他工具在開頭說「你現在是整理員」就好。

## 5 分鐘開始

### 1 · 下載（1 分鐘）

1. 在這一頁最上面，按綠色的 **Code** 按鈕 → **Download ZIP**。
2. 解壓縮：
   - Windows：在下載的檔案上按右鍵 → **全部解壓縮**。
   - Mac：點兩下那個檔案。
3. 把解壓出來的資料夾改名成 `my-hq`（或任何你喜歡的名字），放在你找得到的地方，例如「文件」裡面。

> 會用 git 的人：`git clone https://github.com/dustynotesai/ai-workflow-template.git my-hq`

### 2 · 把你的檔案放進 `raw/`（2 分鐘）

先挑**一件你正在做的事**就好，不用一次全放。照種類放，不照事情放：

| 你的檔案 | 放進 |
|---|---|
| 成效表、Excel、CSV、清單 | `raw/表格/` |
| 家人朋友的群組討論、電話後記的重點、會議紀錄 | `raw/對話/` |
| 品牌表、發過的貼文、合約、訂單、收據 | `raw/文件/` |
| 查到的價格、報價、規定 | `raw/查的資料/` |

用**複製**的，不要剪下：原本的檔案留在原本的地方，當作備份。

### 3 · 用 AI 工具打開這個資料夾（1 分鐘）

三個選一個，打開以後選「打開資料夾」（Open Folder），選 `my-hq`：

- **Claude Code**：Claude 的桌面 app 裡就有，要 Claude 的付費方案。
- **Codex**：OpenAI 的，用 ChatGPT 帳號登入。
- **Cursor**：一個編輯器，裡面有 AI。

它們都會先讀 `AGENTS.md`（Claude Code 透過 `CLAUDE.md` 讀到同一份），所以一打開就知道這個資料夾的規則。

### 4 · 貼第一句話（1 分鐘）

打開 [`prompts/01-第一次整理.md`](prompts/01-第一次整理.md)，整段複製，貼給 AI。

它會讀你放進 `raw/` 的檔案，在 `wiki/` 寫筆記、給每一頁一個編號，最後告訴你它做了什麼。再用 [04 新增一個專案](prompts/04-新增專案.md) 把你正在做的事加進地圖。這些工具第一次要寫檔案時通常會先問你，按「允許」就好。

### 範例檔案要刪嗎？

看懂了就可以刪：檔名或標題有「範例」的檔案、`wiki/品牌資料.md`、`wiki/貼文成效.md`、`wiki/projects/` 裡的兩頁、`projects/` 裡的兩個資料夾。再把 `AGENTS.md` 地圖、`wiki/index.md`、`wiki/log.md`、`wiki/做法清單.md` 裡標「範例」的那幾行刪掉。

指到範例的句子也一起刪，不然連結會壞：`raw/` 各資料夾跟 `wiki/lessons/` 的 `README.md` 最後一行「範例：…」、`prompts/05`、`prompts/06` 最後講範例的那一句、這份 README 的地圖表跟「一個例子」。

也可以直接跟 AI 說：「照 README 的清單把範例刪掉。」它刪之前會先問你。範例的店、人、顏色、數字都是虛構的。

## 沒有這些工具？

一般的 ChatGPT 或 Claude 網頁版也能用一半：開一個新對話（或「專案」），先把 `AGENTS.md` 跟 `wiki/lessons/` 的內容貼進去，再上傳你要它看的檔案。它不能自己在你的電腦裡寫筆記、改專案頁，要你自己存回去。

## 要注意的

- **工作的資料，先看公司准不准用這些 AI 工具。** 檔案在你自己的電腦上，但 AI 讀到的內容會送到那家公司的伺服器處理。
- 身分證字號、帳號、卡號、地址，放進 `raw/` 之前想一下要不要先遮掉。
- 用 git 的人：這個資料夾放了你的檔案以後，**不要推到公開的 GitHub**，要推就開私人 repo。
- AI 會寫錯。所以每一句筆記都要連回原始檔：它講錯的時候，你點進去就查得到是哪一份寫的。教訓也一樣：每一條都連回你的原話。

## 這個做法是誰想的

資料的放法來自 Andrej Karpathy 的〈[LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)〉（2026 年 4 月 4 日發在 GitHub Gist）。他把它分成三層：原始檔（raw sources）、AI 寫的 wiki、告訴 AI 怎麼做的規則檔；`index.md` 當目錄，`log.md` 按時間記發生了什麼。他的一句話：

> "the wiki is a persistent, compounding artifact."

意思是：整理一次，之後一直更新、越積越多，不用每問一次就從頭找一次。

這個起手包照他的三層來放，另外多了幾樣：一張管所有專案的地圖跟專案頁、`wiki/lessons/`（AI 學到的你）、收尾的 `capture`、目錄的編號、三個照工作分的 AI 角色、`prompts/`（複製貼上的話）。規則檔用 [AGENTS.md](https://agents.md/) 這個很多 AI 工具都認得的格式。

**你不需要 AI 什麼都記得，你需要它知道去哪裡找，而且記得你說過的話。**
