# wiki/lessons：AI 學到的你

你的習慣、喜好、糾正過它的事，一條一份。**AI 每次開工前都會讀這裡**（階段是「試用中」「保留」的），照做，做了就在那條的「套用紀錄」加一行。

怎麼來的：你糾正 AI → 它先改對 → 把你的原話存進 `raw/回饋/` → 照 [`templates/教訓.md`](../../templates/教訓.md) 寫一條，階段「試用中」。

| 階段 | 意思 |
|---|---|
| 試用中 | 新的，照做 |
| 保留 | 套用 3 次以上都沒再被糾正。AI 會問你要不要升級，你說好才改 |
| 淘汰 | 不再適用。不刪檔，寫上哪一天、為什麼 |

同一件事被糾正第二次：除了這裡，也加一行到那個專案的「這個專案的規則」（每個專案都適用就加進 `AGENTS.md` 的規則）。

**教訓跟著你，不跟著專案。** 在日本旅行學到的「不排早上的行程」，排搬家的時候也照做。

範例：[不排早上的行程](範例-不排早上的行程.md)、[預算要抓緊](範例-預算要抓緊.md)（都是日本旅行學到、搬家用上的）
