# raw/客戶回饋：客戶回饋

放：客服紀錄、客訴單、客戶寄來的信、問卷結果、業務轉達的話、客戶訊息的截圖。

- 從客服系統或表單匯出的 Excel、CSV 也放這裡，檔名開頭放匯出的日期：`2026-10-22-客戶回饋匯出.csv`。
- 每個月、每次匯出存一份新的，舊的留著：之後才比得出這個月跟上個月差在哪。
- **放進來就不改。** 要分類、數筆數，叫 AI 在 `projects/` 裡做一份新的（[05 處理表格](../../prompts/05-處理表格.md)）。
- 客戶的電話、地址、身分證字號，放之前想一下要不要先遮掉。
