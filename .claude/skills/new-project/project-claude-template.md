# 【專案名】

【一句話：這是什麼。】做到哪、下一步、已決定的事：`[專案頁](../../knowledge/wiki/projects/【專案短名】.md)`（換成真的連結，拿掉反引號）。

這個資料夾只放這件事**做出來的東西**（文件、計畫、清單、草稿）。資料不放這裡：原始檔在 `knowledge/raw/`，整理好的在 `knowledge/wiki/notes/`。

## 這個專案的規則

主人講過、只跟這件事有關的，寫在這裡。每個專案都適用的，寫成教訓（`knowledge/wiki/lessons/`）。
