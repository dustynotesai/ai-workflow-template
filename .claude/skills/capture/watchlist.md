# 做法清單：主人教過幾次的事

主人教 AI「這件事怎麼做」，而且之後還會再做的（整理每月支出、排行程、寫一種信），記在這裡。收尾的時候（[capture](SKILL.md)）AI 自己更新。

- 主人教了一次：他的話一字不改加到 `knowledge/raw/how-tos/<這件事>.md`，這裡加一行，次數 1。
- **照意思比，不照字面。**「整理每月支出」「這個月花了多少」「記帳加總」可能是同一件事。不確定就問一句：「這跟〈整理每月支出〉是同一件事嗎？」
- 到 **3 次**：AI 問主人要不要寫成固定做法（`.claude/skills/<英文短名>/SKILL.md`，用 [skill-template.md](skill-template.md)，只用存下來的話）。主人說好才寫，寫好填最後一欄。
- 固定做法用過一次、沒再重講，這一行就可以刪掉。
