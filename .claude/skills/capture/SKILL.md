# 收尾：下次不用重講

AI 不會自己記得。這個資料夾記得：所以每次做完，問自己一句——

**下次開新對話，主人還要再跟 AI 講一次這件事嗎？**

- 不用 → 什麼都不寫，也不用提。
- 要 → 寫**最小的那一份**，放在下表對的地方。最後一行告訴主人：`已記：<寫在哪>`。

不用先問主人要不要記（小事不要拿去問他）；他不同意會說，再改。

## 寫什麼、寫在哪

| 發生了什麼 | 寫什麼 | 寫在哪 |
|---|---|---|
| 小改、一看就懂的 | 不寫 | — |
| 一段做完了（大綱好了、報告交了） | 一行：日期＋做完什麼；再改「現在做到哪」「下一步」「更新」 | 專案頁 `wiki/projects/<專案>.md` |
| 主人做了一個之後可能被重新討論的決定 | 一行：日期・決定・為什麼 | 專案頁的「已決定」；原本在「還沒決定的事」的，從那裡刪掉 |
| 做的時候冒出一個要主人選、他還沒回答的問題 | 一行：問題＋「還沒決定」 | 專案頁的「還沒決定的事」 |
| 只跟這個專案有關的注意事項 | 一行 | `projects/<專案>/README.md` 的「這個專案的規則」 |
| **主人糾正你** | 一條教訓 | 照下面「糾正 → 教訓」 |
| 同一件事被糾正第二次 | 教訓之外再加一行 | 那個專案的規則；每個專案都適用就加進 `AGENTS.md` 的「規則」 |
| 主人教你**怎麼做**一件之後還會做的事 | 他的話＋次數 | 照下面「教過的做法 → 固定做法」 |
| 同一種工作講了 2–3 次，現有的三個角色都不太對 | 建議加一個角色 | 跟主人說，不要自己建 |

## 糾正 → 教訓

1. 先把東西改對。
2. 主人的原話**一字不改**存到 `raw/回饋/YYYY-MM-DD-主題.md`。同主題已經有一份，就在最下面加一段 `## YYYY-MM-DD · 誰`。
3. 看 `wiki/lessons/` 有沒有同一件事：有就更新那一條；沒有就照 `templates/教訓.md` 寫一條，階段「試用中」。
4. `wiki/index.md` 的「教訓」那一區加一行，`wiki/log.md` 記一筆。
5. 告訴主人：`已記成教訓：wiki/lessons/<檔名>`。

## 套用教訓

- 開工前讀 `wiki/lessons/`（試用中、保留）。照做了一條，就在它的「套用紀錄」加一行：日期、專案、改了什麼。
- 一條套用 3 次以上都沒再被糾正：問主人「要不要升成保留？」，說好才改。
- 一條不再適用：階段改「淘汰」，寫日期跟原因，不刪檔。

## 教過的做法 → 固定做法

1. 主人的說明**一字不改**加到 `raw/做法/<這件事>.md`（新的一段寫日期）。
2. 在 `wiki/做法清單.md` 找同一件事。**照意思比，不照字面**；不確定就問一句：「這跟〈…〉是同一件事嗎？」有就次數 +1、加日期、把新說法加進「也叫做」；沒有就加一行。
3. 到 3 次：問主人「這件事你已經教我 3 次了，要不要寫成固定做法？之後說一句我就照做。」
4. 主人說好：照 `templates/固定做法.md` 寫 `.claude/skills/<英文短名>/SKILL.md`，**只用 `raw/做法/` 裡存的話**；在 `AGENTS.md` 的「固定做法」表加一行，`做法清單.md` 填最後一欄。

## 規則

- 同一件事只寫在一個地方，其他地方連過去。
- 原話一字不改，不替主人編他沒說的話。
- 寫日期（2026-10-28），不寫「下週」「明天」。
- 改 `AGENTS.md` 之前看一下長度：一條規則一行，舊的不用了就刪掉再加。
