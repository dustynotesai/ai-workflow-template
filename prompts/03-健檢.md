# 03 健檢

一個星期一次，貼這段。它只檢查、列清單，不會自己改。

```text
先讀 AGENTS.md。請幫這個資料夾做一次健檢，只列出問題，先不要改：

1. 連結壞掉：點了會找不到檔案的連結（wiki/、projects/、AGENTS.md 裡的都算）。
2. 沒有出處：筆記裡的數字、日期、引句後面沒有連回 raw/ 的。
3. 對不上：筆記寫的數字，跟它連到的原始檔不一樣。
4. 目錄沒跟上：wiki/ 裡有、但 wiki/index.md 沒列的頁，或 index 列了、檔案卻不在的。
5. 編號有問題：沒有編號的筆記、兩頁用了同一個號碼、筆記最上面的編號跟 index 不一樣。
6. 地圖沒跟上：projects/ 裡有、但 AGENTS.md 地圖沒有的資料夾，或地圖有、卻沒有專案頁的。
7. 專案頁太久沒更新：「更新」超過 14 天的；「下一步」寫「下週」「明天」、沒有日期的。
8. 教訓：沒有階段或量法的；套用 3 次以上還是「試用中」的（問我要不要升成保留）；raw/回饋/ 找不到它引的原話的。
9. 做法清單：次數到 3、還沒寫成固定做法的。
10. 一直沒確認：「需要人工確認」裡放了很久還沒勾掉的。

用表格列出來：哪一個檔案、什麼問題、建議怎麼修。最後問我要修哪幾個。
```
