# 03 健檢

一個星期一次，貼這段。它只檢查、列清單，不會自己改。

```text
先讀 AGENTS.md。請幫 wiki/ 做一次健檢，只列出問題，先不要改：

1. 連結壞掉：點了會找不到檔案的連結（wiki/、projects/、AGENTS.md 裡的都算）。
2. 沒有出處：數字、日期、引句後面沒有連回 raw/ 的。
3. 對不上：筆記寫的數字，跟它連到的原始檔不一樣。
4. 目錄沒跟上：wiki/ 裡有、但 wiki/index.md 沒列的頁，或 index 列了、檔案卻不在的。
5. 編號有問題：沒有編號的頁、兩頁用了同一個號碼、筆記最上面的編號跟 index 不一樣。
6. 互相矛盾：兩頁筆記對同一件事說法不一樣。
7. 可能過期：客戶回饋、報表這類，原始檔超過 3 個月的。
8. 一直沒確認：「需要人工確認」裡放了很久還沒勾掉的。
9. 地圖沒跟上：projects/ 裡有、但 AGENTS.md「專案」表沒有的資料夾，或反過來。

用表格列出來：哪一個檔案、哪一行、什麼問題、建議怎麼修。最後問我要修哪幾個。
```
