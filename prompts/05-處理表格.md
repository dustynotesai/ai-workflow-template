# 05 處理表格（例子：記帳）

記帳表、清單這種 Excel、CSV，要加總、分類、比較的時候，貼這段。

```text
先讀 AGENTS.md，照裡面的規則做。

請處理 raw/表格/ 裡的【例如：範例-2026-10-25-家庭記帳.csv】：
1. 先告訴我這份有哪些欄位、有幾筆，還有你打算怎麼算。等我說好再做。
2. 照【例如：類別】加總；再照【例如：付款】加總一次。【例如：「基金」「存錢」不算花掉的錢】
3. 結果存成一份新的表放在 projects/【例如：家庭記帳】/，raw/ 裡的原始檔不要動。
4. 先看 wiki/index.md：已經有同主題的筆記（例如 001 家庭預算），就更新那一頁；沒有才開新的一頁、給下一個編號。每個數字連回原始檔，寫出是哪幾筆。更新 wiki/index.md 跟 wiki/log.md。

需要安裝什麼才能讀 Excel 的話，先告訴我要裝什麼、為什麼，等我說好。
```

範例做出來的樣子：[raw 的記帳表](../raw/表格/範例-2026-10-25-家庭記帳.csv) → [001 家庭預算](../wiki/家庭預算.md)。

你每次都要多交代一樣的話（例如「存錢不算花掉」）？那就是 AI 該學的做法：收尾時它會記進 [做法清單](../wiki/做法清單.md)，到第 3 次會問你要不要寫成固定做法。
