# 05 處理表格（例子：客戶回饋）

客戶回饋、客服紀錄這種 Excel、CSV，要分類、數筆數、找出還沒處理的時候，貼這段。

```text
先讀 AGENTS.md，照裡面的規則做。

請處理 raw/客戶回饋/ 裡的【例如：範例-2026-10-22-客戶回饋匯出.csv】：
1. 先告訴我這份有哪些欄位、有幾筆，還有你打算怎麼數。等我說好再做。
2. 照【例如：類別】分，每一類有幾筆；再照【例如：管道】分一次。
3. 列出狀態還不是「已處理」的，每一筆寫日期、客戶、內容。
4. 結果存成一份新的表放在 projects/【例如：客服改善】/，raw/ 裡的原始檔不要動。
5. 先看 wiki/index.md：已經有同主題的筆記（例如 001 客戶常見問題），就更新那一頁；沒有才開新的一頁、給下一個編號。每個數字連回原始檔，寫出是哪幾筆。更新 wiki/index.md 跟 wiki/log.md。

需要安裝什麼才能讀 Excel 的話，先告訴我要裝什麼、為什麼，等我說好。
```

範例做出來的樣子：[raw 的客戶回饋](../raw/客戶回饋/範例-2026-10-22-客戶回饋匯出.csv) → [001 客戶常見問題](../wiki/客戶常見問題.md) 的「重點」那張表。
