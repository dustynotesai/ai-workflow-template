# 06 幫我做一個東西

要做一份文件、一篇貼文、一張封面、一個計畫，或任何要照你的習慣做的東西時，貼這段，把【】換成你的。

```text
你是製作（Claude Code 裡用 maker）。先讀 AGENTS.md，照「開工前」做，特別是 knowledge/wiki/lessons/：跟這次有關的教訓都要照做。

我要：【例如：做一份給客戶的報價單，放在 projects/【專案】/】

請：
1. 先告訴我你讀到哪幾條教訓、這次會怎麼照做。
2. 要用的資料從 knowledge/wiki/ 跟 knowledge/raw/ 拿，不要自己猜，也不要另外抄一份。
3. 做好放進專案資料夾，交給檢查員（reviewer）照教訓的量法對一遍，再給我。
4. 找不到的、要我決定的，寫進專案頁「還沒決定的事」，先問我，不要猜。
5. 更新專案頁、knowledge/wiki/index.md、knowledge/wiki/log.md。

最後用 3 行告訴我：照了哪幾條教訓、放在哪、要我決定的有幾個。
```
