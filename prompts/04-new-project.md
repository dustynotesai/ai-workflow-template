# 04 新增一個專案

開始一件新的事時，貼這段，把【】換成你的。

```text
你是組長（Claude Code 裡用 lead）。先讀 AGENTS.md，照 .claude/skills/new-project/SKILL.md 新增一個專案：

- 名字：【例如：買新冰箱】
- 要做到什麼：【例如：12 月前買一台雙門冰箱，2 萬元以內】
- 截止：【例如：2026-12-15，沒有就寫「沒有」】
- 放在哪：【不寫就放 projects/ 下面；已經有資料夾或 repo 的話，寫它在哪】
- 英文短名：【例如：new-fridge。不寫就你幫我取】

最後告訴我：建議的前 3 個下一步、用得到哪幾條教訓、我應該先放哪些檔案進 knowledge/raw/。
```
