# 06 幫我做貼文（例子：IG 輪播）

要做一篇貼文、一張封面，或任何要照你的風格做的東西時，貼這段，把【】換成你的。

```text
你是專案助手（Claude Code 裡用 project-helper）。先讀 AGENTS.md，照「開工前」做，特別是 wiki/lessons/：這次要做的事跟教訓有關的，都要照做。

我要：【例如：做一篇 IG 輪播，介紹淺焙跟深焙差在哪，放在 projects/我的IG/】

請：
1. 先告訴我你讀到哪幾條教訓、這次會怎麼照做。
2. 品牌顏色、版型從 wiki/ 跟 raw/文件/ 拿，不要自己猜，也不要另外抄一份。
3. 做好放進專案資料夾，更新專案頁、wiki/index.md、wiki/log.md。
4. 找不到的、要我決定的，寫進專案頁「還沒決定的事」，先問我，不要猜。

最後用 3 行告訴我：照了哪幾條教訓、放在哪、要我決定的有幾個。
```

範例可以看 [第二篇貼文](../projects/我的IG/第二篇-淺焙深焙.md) 跟 [YouTube 封面](../projects/我的YouTube/封面-第一次手沖.md)：開工先讀教訓，沒交代也照做。
