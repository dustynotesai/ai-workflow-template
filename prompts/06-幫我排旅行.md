# 06 幫我排旅行（例子：日本旅行）

要排一趟旅行、一個活動、任何「有日期、有預算」的計畫時，貼這段，把【】換成你的。

```text
你是專案助手（Claude Code 裡用 project-helper）。先讀 AGENTS.md，照「開工前」做，特別是 wiki/lessons/：那是我的習慣，照做。

我要：【例如：12/5 到 12/9 去京都大阪，兩個人，伏見稻荷跟奈良一定要去，住車站附近】

請：
1. 先告訴我你讀到哪幾條教訓、這次會怎麼照做。
2. 預算從 wiki/ 的筆記拿（例如 001 家庭預算的旅行基金），不要另外抄一份記帳表。第一段寫「能用多少」。
3. 價格要上網查的，先存成 raw/查的資料/YYYY-MM-DD-主題.md，再用。
4. 排每天的行程、算錢；要我挑的（機票、住宿）列出選項。
5. 存在 projects/【例如：日本旅行】/，更新專案頁、wiki/index.md、wiki/log.md。
6. 不要幫我訂、不要付錢。

最後用 3 行告訴我：合計多少、還剩多少、要我挑的有幾個。
```

範例做出來的樣子：[`projects/日本旅行/行程.md`](../projects/日本旅行/行程.md)。第一版被糾正兩次，變成兩條教訓；之後排 [搬家](../projects/搬家/搬家計畫.md) 的時候，沒交代也照做了。
