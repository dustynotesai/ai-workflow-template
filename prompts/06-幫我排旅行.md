# 06 幫我排旅行（例子：花蓮三天）

要排一趟旅行、一個活動、任何「有日期、有預算」的計畫時，貼這段，把【】換成你的。

```text
你是專案助手（Claude Code 裡用 project-helper）。先讀 AGENTS.md，照「開工前」做，特別是 wiki/lessons/：那是我的習慣，照做。

我要：【例如：12/5 到 12/7 去花蓮，兩個人，太魯閣一定要去，住車站附近】

請：
1. 先告訴我你讀到哪幾條教訓、這次會怎麼照做。
2. 預算從 wiki/ 的筆記拿，不要另外抄一份表。第一段寫「能用多少」。
3. 價格要上網查的，先存成 raw/查的資料/YYYY-MM-DD-主題.md，再用。
4. 排每天的行程、算錢；要我挑的（車票、住宿）列出選項。
5. 存在 projects/【例如：花蓮三天】/，更新專案頁、wiki/index.md、wiki/log.md。
6. 不要幫我訂、不要付錢。

最後用 3 行告訴我：合計多少、還剩多少、要我挑的有幾個。
```

範例裡沒有旅行。一樣的做法（開工先讀教訓、沒交代也照做）可以看 [YouTube 封面](../projects/我的YouTube/封面-第一次手沖.md)。
