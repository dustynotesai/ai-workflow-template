# 01 整理

第一次用，或每次放了新檔案進 `knowledge/raw/` 之後，貼這段。

```text
先讀 AGENTS.md，照裡面的規則做。你是研究員（Claude Code 裡用 researcher）。

請照 .claude/skills/wiki/SKILL.md 的「整理」，整理 knowledge/raw/ 裡還沒整理過的檔案（knowledge/wiki/log.md 沒有記過的就是還沒整理的）：
1. 一份一份讀。看不懂或打不開的，列出來告訴我，先跳過。
2. 一個主題在 knowledge/wiki/notes/ 寫一頁。已經有同主題的頁（先看 knowledge/wiki/index.md），就更新那一頁，不要再開一頁。
3. 每一個數字、日期、引句，後面都連回它的原始檔，而且在原始檔找得到一模一樣的字。找不到的不要寫；互相矛盾、沒寫清楚的，放進「需要人工確認」。
4. 跟某個專案有關的，在那個專案的專案頁「用到的筆記」加上連結。筆記照「這是什麼」取名，不照專案取名，別的專案才用得到。
5. 更新 knowledge/wiki/index.md 跟 knowledge/wiki/log.md。
6. knowledge/raw/ 裡的檔案不要改、不要改名、不要搬。

做完用 5 行以內告訴我：新增了哪幾頁、更新了哪幾頁、有哪些檔案看不懂、有哪些要我人工確認。
```

檔案很多的話，可以在第一行後面加一句：「這次只整理 knowledge/raw/【資料夾名】/ 就好。」

整理完的樣子：[`knowledge/wiki/index.md`](../knowledge/wiki/index.md) 裡一頁一行，有一句話跟更新日期。
