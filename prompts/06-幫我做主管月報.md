# 06 幫我做主管月報（例子：客戶最常反映的問題）

主管突然要一份報告的時候，貼這段，把【】換成你的。

```text
你是專案助手（Claude Code 裡用 project-helper）。先讀 AGENTS.md，照裡面「找資料的順序」做。

主管說：「【例如：下週一要報告，幫我整理這個月客戶最常反映的問題。】」

請：
1. 先看 AGENTS.md 的專案表跟 wiki/index.md，找有沒有已經整理好的筆記（別的專案整理的也算），告訴我你找到哪幾頁（編號跟名字）。不要一開始就把每個檔案讀一遍。
2. 從那幾頁筆記做一份簡報大綱，5 到 7 點，每一點後面標是從哪一頁筆記來的。
3. 筆記裡「需要人工確認」的事，全部列在大綱最後，寫我要問誰。
4. 筆記沒有的、看起來過時的，才回去看 raw/ 的原始檔；raw/ 也沒有，就寫「資料裡沒有」，不要猜。
5. 大綱存在 projects/【例如：主管月報】/README.md，更新 AGENTS.md 專案表那一行，在 wiki/log.md 記一筆。

最後用 3 行告訴我：用了哪幾頁筆記、大綱有幾點、報告前我要確認哪幾件事。
```

範例做出來的樣子：[`projects/主管月報/README.md`](../projects/主管月報/README.md)。
