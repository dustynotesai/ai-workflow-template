# 03 健檢

一個星期一次，貼這段。它只檢查、列清單，不會自己改。

```text
先讀 AGENTS.md。請照 .claude/skills/wiki/SKILL.md 的「健檢」，幫這個資料夾做一次健檢，只列出問題，先不要改：

1. 連結壞掉：點了會找不到檔案的連結。
2. 沒有出處：筆記裡的數字、日期、引句沒有連回原始檔，或在原始檔找不到一模一樣的字。
3. 目錄沒跟上：knowledge/wiki/ 有、但 index.md 沒列的頁，或列了、檔案卻不在的；「更新」日期對不上的。
4. 地圖沒跟上：projects/ 裡有、但沒有專案頁的資料夾。
5. 專案頁太久沒更新：「更新」超過 14 天的；「下一步」寫「下週」「明天」、沒有日期的。
6. 教訓：沒有階段或量法的；套用 3 次以上還是「試用中」的（問我要不要升成保留）；原話在 knowledge/raw/feedback/ 找不到的。
7. 做法清單：次數到 3、還沒寫成固定做法的。
8. 重複跟矛盾：兩頁講同一件事的、互相矛盾的、「需要人工確認」放了很久的。

電腦有 Python 的話，先跑 python tools/check_wiki.py . 再用看的。
用表格列出來：哪一個檔案、什麼問題、建議怎麼修。最後問我要修哪幾個。
```
