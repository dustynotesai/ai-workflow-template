# 02 問問題

想問你的資料裡有什麼的時候，貼這段，把最後一行換成你的問題。

```text
你是分析員（Claude Code 裡用 analyst）。先讀 AGENTS.md，照裡面「找資料的順序」：先看 wiki/index.md 的編號跟一句話，再打開有關的筆記，需要查證時才打開 raw/ 的原始檔。不要一開始就把每個檔案讀一遍。

回答的時候：
- 每一個數字、日期後面標出是從哪一份檔案來的。
- 資料裡沒有的，直接說「資料裡沒有」，不要猜。
- 原始檔互相矛盾的，兩個都寫出來。
- 這個答案值得留下來的話，問我要不要存成一頁筆記。

我的問題：【例如：這個月客戶最常反映哪三個問題？哪些還沒處理完？還缺什麼資料？】
```
