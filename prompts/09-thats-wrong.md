# 09 這裡錯了：教 AI 記住你

AI 做出你不要的東西時，貼這段，把【】換成你想說的。照你的原話寫就好，不用講得很完整。

```text
這裡錯了：【例如：報告先寫結論，背景放後面。以後都這樣。】

請照 .claude/skills/capture/SKILL.md 的「糾正 → 教訓」：
1. 先改對。
2. 我的原話一字不改，存到 knowledge/raw/feedback/。
3. 看 knowledge/wiki/lessons/ 有沒有同一件事：有就更新那一條，沒有就寫一條，階段「試用中」。規則寫成每個專案都用得上的樣子，不只這一次。
4. 更新 knowledge/wiki/index.md、knowledge/wiki/log.md。
5. 告訴我：「已記成教訓：檔名」，還有你覺得其他哪些專案也會用到。
```

之後每次開工，AI 都會先讀 `knowledge/wiki/lessons/`，不管是哪個專案。照做 3 次都沒再被你糾正，它會問你要不要把這條升成「保留」。
