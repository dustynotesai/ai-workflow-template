# 05 處理表格

支出表、清單、成績、報價這種 Excel、CSV，要加總、分類、比較的時候，貼這段。

```text
先讀 AGENTS.md，照裡面的規則做。你是製作（Claude Code 裡用 maker）。

請處理 knowledge/raw/references/ 裡的【檔名，例如：2026-10-expenses.csv】：
1. 先告訴我這份有哪些欄位、有幾筆，還有你打算怎麼算。等我說好再做。
2. 照【例如：類別】加總；再照【例如：誰付的】加總一次。
3. 結果存成一份新的表放在 projects/【專案】/，原始檔不要動。
4. 先看 knowledge/wiki/index.md：已經有同主題的筆記，就更新那一頁；沒有才開新的一頁。每個數字連回原始檔，寫出是哪幾筆。更新 index.md 跟 log.md。

需要安裝什麼才能讀 Excel 的話，先告訴我要裝什麼、為什麼，等我說好。
```

你每次都要多交代一樣的話（例如「先分類再加總」）？那就是 AI 該學的做法：收尾時它會記進做法清單，到第 3 次會問你要不要寫成固定做法。
