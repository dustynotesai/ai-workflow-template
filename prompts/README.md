# prompts：複製貼上的話

打開一份，把灰色框裡的整段複製，貼給 AI。`【】` 裡的換成你的。

## 整理你的資料夾

| 檔案 | 什麼時候用 |
|---|---|
| [01 第一次整理](01-第一次整理.md) | 第一次用，或每次放了新檔案進 `raw/` |
| [02 問問題](02-問問題.md) | 想問你的資料裡有什麼 |
| [03 健檢](03-健檢.md) | 一個星期一次：連結壞掉、沒有出處的數字、編號亂掉、過期的頁 |
| [04 新增專案](04-新增專案.md) | 開始一件新的事 |

## 兩個辦公室的例子

| 檔案 | 例子 |
|---|---|
| [05 處理表格](05-處理表格.md) | 10 月的客戶回饋照類別、管道數筆數，列出還沒處理的 |
| [06 幫我做主管月報](06-幫我做主管月報.md) | 主管說「下週一要報告」：從整理好的筆記做簡報大綱，列出要確認的事 |

01 用整理員、02 用分析員、04–06 用專案助手（角色寫在 `AGENTS.md`）。每一句都已經寫好這個資料夾的規則（原始檔不改、先看目錄、要動東西先問你），所以不用自己再提醒它。
