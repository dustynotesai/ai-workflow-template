# 07 我所有的專案現在做到哪？

開新的對話，想一次看所有事情的進度時，貼這段。

```text
你是分析員（Claude Code 裡用 analyst）。先讀 AGENTS.md。

我所有的專案現在做到哪？

只讀 AGENTS.md 的地圖跟 wiki/projects/ 裡每一頁專案頁就好，不要打開每個專案資料夾。
- 要我決定或確認的，放最前面，一件一行。
- 再來一個專案一行：狀態、下一步、截止日。
- 專案頁「更新」超過 14 天的，標「可能過時」。
- 最後一行：最急的是哪一件，為什麼。
```

答得出來，是因為每次做完，AI 都會更新那個專案的專案頁（做到哪、下一步、更新日期）。
