# 04 新增專案

開始一件新的事時，貼這段，把【】換成你的。

```text
你是專案助手（Claude Code 裡用 project-helper）。先讀 AGENTS.md。我要開始一件新的事：

- 名字：【例如：經銷商說明會】
- 要做到什麼：【例如：12 月辦一場說明會，介紹第二代收銀機】
- 什麼時候要完成：【例如：11 月底前定好場地跟簡報】

請：
1. 在 projects/ 開一個資料夾，裡面寫 README.md，格式照 projects/新品上市/README.md（要做到什麼、現在做到哪、下一步、用到的筆記、決定紀錄）。資料不要放進專案資料夾，連去 wiki/。
2. 在 AGENTS.md 的「專案」表加一行。
3. 看 wiki/index.md 有沒有已經能用的筆記（別的專案整理過的也算），有的話用編號跟名字連進「用到的筆記」，不要重查。
4. 在 wiki/log.md 記一筆。
5. 最後告訴我：你建議的前 3 個下一步，還有我應該先放哪些檔案進 raw/。
```
