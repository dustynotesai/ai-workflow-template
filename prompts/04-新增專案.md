# 04 新增一個專案

開始一件新的事時，貼這段，把【】換成你的。

```text
你是專案助手（Claude Code 裡用 project-helper）。先讀 AGENTS.md。我要新增一個專案：

- 名字：【例如：買新冰箱】
- 屬於哪一區：【例如：家】（地圖裡沒有這一區就開新的一區）
- 要做到什麼：【例如：12 月前買一台雙門冰箱，2 萬元以內】
- 截止：【例如：2026-12-15】
- 放在哪：【不寫就放 projects/【名字】/；已經有資料夾或 repo 的話，寫它在哪】

請：
1. 開資料夾（已經有就不用），裡面放一份 README.md：這個資料夾放什麼、「這個專案的規則」（先空著）。照 projects/搬家/README.md 的樣子。
2. 在 AGENTS.md 的地圖加一行：區域、專案、在哪、一句話、交給誰、專案頁。
3. 照 templates/專案頁.md 寫專案頁 wiki/projects/【名字】.md，日期寫今天。
4. 看 wiki/index.md 有沒有已經能用的筆記（別的專案整理過的也算，例如 001 家庭預算），有的話連進「用到的筆記」，不要重查。
5. 看 wiki/lessons/：哪幾條我的習慣這個專案也用得到，寫在回報裡。
6. 更新 wiki/index.md 的「專案頁」那一區，在 wiki/log.md 記一筆。

最後告訴我：建議的前 3 個下一步、用得到哪幾條教訓、我應該先放哪些檔案進 raw/。
```
