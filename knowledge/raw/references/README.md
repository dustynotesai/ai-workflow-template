# knowledge/raw/references：你的檔案、查來的資料

放：所有專案都可能用到的東西。文件（合約、訂單、收據、說明書）、表格（Excel、CSV、清單、從銀行或平台匯出的表）、上網查的（價格、尺寸、規定）、打電話問來的報價、文章。PDF、照片、Word 都可以。

- 用**複製**的，不要剪下：原本的檔案留在原本的地方，當作備份。
- 你的檔案原本叫什麼就叫什麼。AI 查來的，一個主題一份，寫查的日期跟網址：價格會變，日期很重要。
- 身分證字號、帳號、卡號，放進來之前想一下要不要先遮掉。有密碼的檔案先解開再放。
- **放進來就不改。** 要加總、分類、轉檔，叫 AI 在 `projects/` 裡做一份新的（[05 處理表格](../../../prompts/05-work-with-a-table.md)）。
