# knowledge/raw/projects：每個專案的原始想法

放：一件事一開始的想法、需求、要做到什麼，還有跟它有關的討論（群組對話、電話後記的重點、會議紀錄）。

- 一個專案一份，檔名用專案的英文短名（`new-fridge.md`）。新的討論加在最下面一段 `## 日期 · 誰`。
- 原本長什麼樣就放什麼樣，複製貼上或截圖都可以。要重點，叫 AI 整理（[01 整理](../../../prompts/01-organize.md)）。
- 所有專案都可能用到的資料（報價、規定、文章），放 [`references/`](../references/README.md)。
- **放進來就不改。**
